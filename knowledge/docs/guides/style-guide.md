# Style Guide

- Usa títulos con guiones medios en nombres de archivo y evita espacios.
- Prefiere párrafos cortos y listas de 3-5 ítems para reforzar claridad.
- Incluye CTAs visibles al final de cada sección que orienten el siguiente paso.
- Referencia principios relevantes para justificar decisiones clave.
- Mantén enlaces relativos y verifica su validez con `operations/scripts/check-links.py`.
