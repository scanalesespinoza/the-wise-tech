- **TTFC < 1 día**: ejemplos pequeños, Make targets claros.
- **Revisiones con propósito**: pedir evidencia mínima (smoke, p95, enlaces).
- **CODEOWNERS**: responsables visibles; usa etiquetas `good-first-issue`, `help-wanted`.
