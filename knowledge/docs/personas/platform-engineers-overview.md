# Platform Engineers — Overview
## Primeros 10 minutos
1) make -f operations/Makefile install && make -f operations/Makefile parity && make -f operations/Makefile docs
2) Revisa políticas/guías de resiliencia (si existen)
3) Verifica enlaces internos de docs (script o CI)

## First win (≤ 60 min)
- Añade/valida un check simple (links o lint) en CI.
- Documenta el cambio en “Guides”.

- Plantillas de Issues/PR para capturar señales (si existen); si no, proponerlas.
