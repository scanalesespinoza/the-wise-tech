# Practices — The Hadron Pattern for Microservices

## Quick checklist (≤10 ítems)
- [ ] Catalogar microservicios individuales (quarks) con responsabilidades claras.
- [ ] Definir agrupaciones (hadrons) y objetivos compartidos.
- [ ] Implementar servicios de coordinación (mesons) con monitoreo y healing.
- [ ] Diseñar interfaces (baryons) con contratos y SLAs visibles.
- [ ] Mapear dependencias entre capas y mantenerlas actualizadas.
- [ ] Validar resiliencia de hadrons mediante pruebas de fallos cruzados.
- [ ] Documentar aprendizajes de incidentes por cada rol del patrón.
- [ ] Revisar periódicamente si algún quark debe promoverse a hadron o baryon.

## How-to (pasos accionables)
1) Elaborar un catálogo de servicios clasificándolos según el patrón y asignar responsables por rol.  
2) Configurar mallas de observabilidad que alimenten a los coordinadores con métricas de salud, discovery y recuperación.  
3) Establecer revisiones arquitectónicas trimestrales donde se evalúe la alineación del patrón con objetivos de negocio y se ajusten las agrupaciones.

## KPIs / Leading indicators
- Tiempo de descubrimiento y recuperación gestionado por mesons.
- Cantidad de incidentes resueltos sin intervención humana directa.
- Cumplimiento de contratos expuestos por baryons.
- Número de mejoras documentadas tras revisiones del patrón.
