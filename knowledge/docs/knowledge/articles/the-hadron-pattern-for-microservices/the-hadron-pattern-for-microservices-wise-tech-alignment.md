# Wise Tech Alignment — The Hadron Pattern for Microservices

| Topic/Claim | Insight | Wise Tech Principle(s) | Why it matters |
|---|---|---|---|
| Quarks como unidades básicas | Microservicios autónomos en capas de despliegue y funcionalidad. | simplicity, resilience | Favorece límites claros y recuperación independiente. |
| Hadrons colaborativos | Agrupaciones orientadas a objetivos superiores. | human-connection, knowledge-capitalization | Requiere coordinación consciente y aprendizaje compartido. |
| Mesons coordinadores | Servicios que descubren, recuperan y sanan. | resilience, continuous-improvement | Mantienen loops de feedback operativos y mejoran la estabilidad. |
| Baryons como interfaces | Servicios que exponen o consumen capacidades. | simplicity, human-purpose | Facilitan comunicación clara con consumidores internos y externos. |

**Loops de feedback propuestos**
- Monitoreo de quarks → Mesons → Ajustes de hadrons → Interfaces hacia usuarios → Retroalimentación a monitoreo.
- Cómo medir impacto humano: tiempo de recuperación, claridad de ownership y satisfacción de consumidores internos.

**Riesgos/antipatrones**
- Ignorar los roles de coordinación y sobrecargar microservicios individuales.
- Diseñar interfaces sin considerar la experiencia de quienes las consumen.
