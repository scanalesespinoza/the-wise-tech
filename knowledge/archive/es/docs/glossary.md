# Glosario Vivo

Mantén la terminología consistente en documentación, comentarios de código, prompts de IA y conversaciones de onboarding. Actualiza este glosario cada vez que aparezcan nuevos términos.

| Término | Definición | Recursos Relacionados |
| ------- | ---------- | --------------------- |
| **aDevelopment** | Práctica de aumentar el desarrollo con minería de conocimiento impulsada por IA, mentoría y automatización. | [Playbook](the-wise-tech-adevelopment.md) |
| **Contexto Esencial** | Identidad innegociable del sistema: principios, políticas y restricciones que siempre deben cumplirse. | [Principios Esenciales](principles-essential.md) |
| **Changelog Narrativo** | Nota de release que explica cambios técnicos junto con impacto de negocio, riesgos y pasos de mitigación. | [Guías de Changelog](changelog-guidelines.md) |
| **Receta** | Instrucciones repetibles basadas en el repositorio que enseñan cómo aplicar un patrón con contexto. | [Catálogo de Recetas](recipes/README.md) |
| **Proceso Simbiótico** | Bucle de retroalimentación entre plataforma, equipos de producto y personas usuarias donde cada iteración fortalece a las demás. | [Diagrama Simbiótico](../symbiotic-process-diagram.md) |

## Cómo contribuir

1. Agrega nuevas filas en orden alfabético.
2. Incluye referencias a documentación, rutas de código o tableros que refuercen la definición.
3. Refleja el cambio en el glosario en inglés.
4. Menciona las actualizaciones al glosario en la descripción del PR para mantener alineado al equipo revisor.
