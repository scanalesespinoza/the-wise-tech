# Enfoque The Wise Tech: Representación visual

## Enfoque tradicional complejo: Cadenas desconectadas

```
+--------------------------------------+
|              CICD                    |
+--------------------------------------+
          |
+--------------------------------------+
|              DevOps                  |
+--------------------------------------+
          |
+--------------------------------------+
|            DevSecOps                 |
+--------------------------------------+
```

- **Procesos desconectados:** Cada etapa opera de forma independiente, lo que genera ineficiencias y debilita la alineación con los resultados para las personas usuarias.

## Enfoque The Wise Tech: Proceso integrado de punta a punta

### 1. Proceso de desarrollo extremo a extremo
```
+--------------------------------------+
|   Desarrollador/a:                   |
|   - Diseño                           |
|   - Desarrollo                       |
|   - Consideraciones de seguridad     |
|   - Despliegue                       |
+--------------------------------------+
```

### 2. Proceso de plataforma extremo a extremo
```
+--------------------------------------+
|   Ingeniero/a de plataforma:         |
|   - Diseño del sistema               |
|   - Resiliencia y escalabilidad      |
|   - Monitoreo y optimización         |
|   - Diseño centrado en el usuario    |
+--------------------------------------+
```

### 3. Bucle de retroalimentación de las personas consumidoras de tecnología
```
+--------------------------------------+
|   Personas consumidoras de tecnología|
|   - Retroalimentación sobre usabilidad|
|   - Reporte de problemas y mejoras   |
|   - Impacto en la calidad de vida    |
+--------------------------------------+
           ↑
           |
+--------------------------------------+
|     Proceso integrado de feedback    |
|   - Desarrolladores/as e ingenieros/as|
|   - Mejora continua                  |
+--------------------------------------+
```

- **Proceso integrado:** Todas las etapas permanecen conectadas mediante retroalimentación continua que mantiene la tecnología con propósito y enfoque humano.

## Resumen
- El **enfoque tradicional** produce flujos aislados y pierde oportunidades de mejora holística.
- El **enfoque The Wise Tech** une a desarrolladores/as, personas ingenieras de plataforma y consumidoras de tecnología mediante un sistema integrado de retroalimentación que garantiza que la tecnología sirva eficazmente a las personas.
