# Living Glossary

Keep terminology consistent across documentation, code comments, AI prompts, and onboarding conversations. Update this glossary whenever new terms appear.

| Term | Definition | Related Assets |
| ---- | ---------- | -------------- |
| **aDevelopment** | Practice of augmenting development with AI-driven knowledge mining, mentoring, and automation. | [Playbook](the-wise-tech-adevelopment.md) |
| **Essential Context** | Non-negotiable identity of the system: principles, policies, and constraints that must always hold. | [Essential Principles](principles-essential.md) |
| **Narrative Changelog** | Release note that explains technical changes plus business impact, risks, and mitigation steps. | [Changelog Guidelines](changelog-guidelines.md) |
| **Recipe** | Repeatable instructions grounded in the repository that teach how to apply a pattern with context. | [Recipe Catalog](recipes/README.md) |
| **Symbiotic Process** | Feedback loop between platform, product teams, and end users where each iteration strengthens the others. | [Symbiotic Diagram](../symbiotic-process-diagram.md) |

## How to contribute

1. Add new rows in alphabetical order.
2. Include references to docs, code paths, or dashboards that reinforce the definition.
3. Mirror the change in the Spanish glossary.
4. Mention glossary updates in the PR description to help reviewers stay aligned.
