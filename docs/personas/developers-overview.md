# Software Developers — Overview
## Primeros 10 minutos
1) make install && make test && make parity && make docs
2) Abre “Scenarios” y ejecuta los tests focalizados (si existen)
3) Revisa “Developer Playbook” (si existe) o guía de buenas prácticas

## First win (≤ 60 min)
- Agrega 1 test o corrige un link/doc.
- Sube un PR pequeño con explicación breve y referencia a un principio de Wise Tech.

## Señales mínimas de calidad
- Tests verdes, paridad bilingüe ok.
- Documentación enlazada desde README.
