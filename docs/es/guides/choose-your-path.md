# Elige tu ruta

Este atajo ahora concentra todo en el **Índice de contenido de valor** del README.

## Paso único
1. Visita el [Índice de contenido de valor](https://github.com/scanalesespinoza/the-wise-tech/blob/main/README.md#value-index).
2. Elige el bloque que corresponda a tu objetivo (orientación, roles, labs, operaciones o feedback).
3. Marca la sección como favorita para volver rápidamente desde GitHub o desde la versión publicada.

## Sugerencias
- Si compartes el índice con tu equipo, añade el bloque exacto en el issue o nota para que no busquen de más.
- Usa el bloque de **Feedback & contributions** para abrir issues o PRs con contexto claro.
- Cuando necesites algo visual, abre también la [Navegación visual](../../visual-navigation.md) y relaciona el bloque correspondiente.
