# Bienvenida a The Wise Tech

The Wise Tech documenta prácticas resilientes, centradas en las personas y accionables. Este sitio prioriza el español como idioma canónico sin perder compatibilidad con rutas y tags en inglés.

## Cómo navegar
- Usa el menú principal para abrir guías base como el Quickstart y el glosario.
- Consulta la cola de traducción para saber qué lotes vienen en camino.
- Ejecuta `make translation-qa` antes de abrir un PR para validar metadatos y enlaces.

## Próximos pasos
1. Revisa la [Migración a español](es/guides/migracion-es.md).
2. Aplica las [reglas de idioma y estructura](guides/content-style-guide.md#reglas-de-idioma-y-estructura).
3. Mantén consistencia terminológica usando el [glosario](es/guides/glosario-terminologia.md).
